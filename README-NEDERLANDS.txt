VYVY WEBSITE MET GRATIS BEHEERPANEEL

Het beheerpaneel staat op:
https://jouw-domein.netlify.app/admin/

BELANGRIJK
Deze versie kan niet alleen met Netlify Drop worden gebruikt als je online wilt opslaan.
De website moet één keer aan een gratis GitHub-repository worden gekoppeld. Daarna kun je alles via /admin wijzigen en publiceert Netlify automatisch.

EENMALIGE INSTALLATIE
1. Maak gratis een account op github.com.
2. Maak een nieuwe repository, bijvoorbeeld: vyvy-website.
3. Upload ALLE bestanden uit deze map naar die repository. Zorg dat de branch 'main' heet.
4. Open Netlify en kies: Add new project > Import an existing project > GitHub.
5. Kies de repository vyvy-website en klik Deploy.
6. Open in Netlify: Project configuration > Identity en schakel Netlify Identity in.
7. Zet Registration preferences op 'Invite only'.
8. Open Identity > Services > Git Gateway en schakel Git Gateway in.
9. Open Identity > Invite users en stuur een uitnodiging naar je eigen e-mailadres.
10. Accepteer de uitnodiging en open daarna: https://jouw-site.netlify.app/admin/

GEBRUIKEN
- Log in via /admin/
- Kies 'Alle teksten, prijzen en foto\'s'
- Pas iets aan
- Klik rechtsboven op 'Publiceren'
- Wacht ongeveer 1–2 minuten; Netlify zet de wijziging automatisch online.

Je kunt beheren:
- bedrijfsnaam, adres, telefoon en Instagram
- Nederlandse en Engelse teksten
- diensten en foto's
- alle prijzen
- over-ons-tekst en foto
- galerij
